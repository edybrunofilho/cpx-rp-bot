## 1. INTRODUÇÃO

A privacidade e a proteção de dados pessoais são prioridades fundamentais para o bot CPX RP (doravante denominado "Bot" ou "Serviço"). Esta Política de Privacidade descreve como coletamos, usamos, armazenamos, protegemos e compartilhamos informações coletadas de usuários.

Ao usar o Bot, você concorda com as práticas descritas nesta política. Se não concordar com nossas práticas, não utilize o serviço.

---

## 2. CONFORMIDADE LEGAL

Esta Política de Privacidade foi elaborada em conformidade com:

- **Lei Geral de Proteção de Dados (LGPD)** - Lei nº 13.709/2018
- **Regulamento Geral sobre Proteção de Dados (GDPR)** - Regulamento (UE) 2016/679
- **Lei Brasileira de Proteção de Dados Pessoais**
- Regulamentações de privacidade internacionais aplicáveis
- Termos de Serviço das plataformas hospedeiras (Discord, Telegram, etc.)

## 3. DEFINIÇÕES

- **Dados Pessoais**: Qualquer informação que identifique ou possa identificar uma pessoa física
- **Dados Sensíveis**: Dados pessoais referentes a origem racial ou étnica, convicção religiosa, opinião política, saúde ou vida sexual
- **Tratamento de Dados**: Qualquer operação realizada com dados pessoais
- **Usuário**: Pessoa que acessa ou utiliza o Bot
- **Controlador de Dados**: A entidade responsável pelo tratamento de dados (proprietário do Bot)
- **Processador de Dados**: Entidade que processa dados em nome do controlador
- **Consentimento**: Concordância livre, informada e inequívoca do Usuário

## 24. PERGUNTAS FREQUENTES SOBRE PRIVACIDADE

### P: Meus dados serão vendidos?
**R:** Não. Nunca vendemos dados pessoais. Essa é uma violação fundamental de nossa política.

### P: Quanto tempo meus dados são mantidos?
**R:** Varia por tipo. Ver seção 9 para detalhes. Geralmente 6-12 meses de uso ativo.

### P: Posso excluir minha conta?
**R:** Sim. Comando `/deletar-conta` ou solicitação por email. Dados são excluídos dentro de 30 dias.

### P: Como você protege contra hackers?
**R:** Múltiplas camadas: criptografia, firewalls, monitoramento 24/7, backups. Ver seção 11.

### P: Você rastreia minha localização?
**R:** Não. Não coletamos dados de localização. Apenas IPs em alguns casos para segurança.

### P: O que fazer se for vítima de violação?
**R:** Será notificado. Contate suporte imediatamente para assistência.

### P: Meus dados são compartilhados com Discord/Telegram?
**R:** Apenas o mínimo necessário para funcionamento. Termos deles também se aplicam.

### P: Como exerço meus direitos?
**R:** Email para dpo@cpxrp.com com tipo de solicitação específico.
